# Stage 1 audit and fixes

Audit date: 2026-10-30 (Asia/Tashkent). Baseline: `49bd494` on `stage-1/components-shell`. Audit branch: `stage-1/audit`.

**Result: Stage 1 is ready to close after these fixes.** Found **0 Critical, 1 High, 8 Medium and 1 Low** findings. All High/Medium findings are fixed; one Low cleanup item remains. This is acceptance of the Stage 1 scaffold, primitives, gallery and shells, not completion of the later catalog/cart/auth/database stages.

## Scope and method

Read AGENTS.md, SPEC.md and DESIGN.md; inspected every source/test file, token generator, locale dictionary, CI workflow, manifests, lockfile importer, runtime/deployment configuration and font provenance. Generated CSS was checked against its generator and both stylesheet sources. Static scans and AST guards exclude tests and license prose when judging runtime UI copy/types; immutable supplied SVGs are intentional palette-containing assets.

Baseline `pnpm lint && pnpm typecheck && pnpm test && pnpm build` passed with **200 tests**, despite the defects below. Passing baseline checks were insufficient. Reproduced input/language/target failures in Chromium: [baseline-browser.json](evidence/baseline-browser.json).

No spec documents or supplied assets were changed, no dependencies were added, and no features were introduced. Existing TypeScript 6.0.3 was pinned exactly without upgrading it.

## Other checks verified OK

- **No unused direct dependencies found.** Runtime imports: next, react, react-dom (portal), next-intl, zod, motion, lucide-react. Tool/test/config imports: typescript, vitest, jsdom (test environment), yaml, prettier, eslint, eslint-config-next, tailwindcss, @tailwindcss/postcss, Testing Library packages. `@types/*` are the associated type inputs.
- No explicit `any` or arbitrary Tailwind radius/spacing/duration values in runtime sources; strict TypeScript remains enabled. License prose containing “any” is not TypeScript usage.
- No network assets, data fetching, local/session storage, mutations, secrets or authentication code added. Browser records zero external requests and zero JS/hydration errors. Font license URLs are provenance, not runtime requests.
- All lists are fixed tabs/token metadata or a bounded twelve-item seed; no unbounded data-source query exists. Future repository pagination requirements remain applicable when such queries are introduced.
- Icon-only controls require/provide localized labels; form labels/descriptions and focus-visible styles are present, including composite search/phone focus treatment. Axe checks run with dialogs both keyboard-exercised and closed-state gallery inspected.
- `.github/workflows/ci.yml` uses Node from `.nvmrc`, pnpm cache, frozen installation and all four required checks. Vercel framework/output settings select Next.js/`.next`; no deployment was performed by this audit.
- Local font licenses, original documents and original SVGs are preserved; no new runtime/tool dependencies were needed for the fixes. Lighthouse ran temporarily through pnpm dlx and was not added to the app.
